# Design references

The two images here are the visual references this interface was built from.

They are **concepts, not specifications.** They show a larger product than the
one that was built: document versions, "request changes", resubmission,
reviewer assignment, an approval route, due dates and a custom PDF toolbar.
None of that exists.

What was taken from them: the forest and ivory palette, the spacing rhythm,
the serif-for-titles type pairing, the sidebar structure and the two-panel
review layout.

What was left out, and why, is covered in the main README under
"The mockups show a larger product".
